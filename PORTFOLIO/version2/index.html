Hello, I'm Khuzaifah

I'm a motivated Software Engineering student at the Uganda Institute of Information and Communications Technology (UICT), working toward my Diploma in Software Engineering. I am passionate about writing software that solves genuine, everyday problems — especially in education, institutions, and communities.

My primary focus is backend development using Python and Django, database engineering with MySQL and SQL, and building RESTful APIs. I also work on the frontend with HTML, CSS, and JavaScript to deliver full, working web applications.

The problems I most enjoy tackling are process inefficiencies — manual systems in schools and institutions that can be improved with well-designed software. My projects, including a Student Attendance System and an E-Consent & Verification System, reflect this interest directly.

I am currently deepening my knowledge in advanced Django, REST API design, Docker, system design, and software architecture. My long-term goal is to become a highly capable Software Engineer with expertise across the full stack, from databases and APIs to interfaces and deployment.
